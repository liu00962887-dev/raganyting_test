    CH.05 · 大模型时代

    大模型这么聪明，为什么还不够？

    提问上个月的活跃客户有多少？

    公司里对“活跃客户”有三种说法：

    销售部90 天内下过单
    财务部有未结清的账款
    客服部30 天内提过工单

    Agent上个月活跃客户约 1,930 个。

    再问一次上个月活跃客户有 2,041 个。

    口径靠猜两次答案不一样说不清出处

    本体定义 · 活跃客户 · v2.3 · 经营委员会确认近 90 天内至少有 1 张已付款订单的客户

    Agent按这个定义，上个月活跃客户 1,284 个。

    客户→下单→订单.状态=已付款→ERP.orders
    口径统一问几次都一样每一步可追溯

    示意数据

    大模型= 大脑：会理解、会推理
    知识图谱= 记忆：记住一条条事实
    本体= 常识和规矩：懂业务、守规则

      理解

    CH.09 · 总结

    三句话记住

    本体

    规则书

    定义有哪些概念、它们之间能有什么关系、要遵守什么规则。

    知识图谱

    事实网

    按规则书记录下来的一条条具体事实：谁、和谁、发生了什么。

    本体平台

    Agent 的企业中枢

    统一语义、连接数据、定义动作、管住权限、全程留痕：让 Agent 看得懂、做得对、管得住。

    大模型让 Agent 会思考，本体让 Agent 懂企业。
